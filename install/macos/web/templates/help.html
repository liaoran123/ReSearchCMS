{{.translator.Translate "advanced_search_tips" .lang}}：
- 如果需要搜索目录名和文件名，只需在关键词前面加<，或在后面加>，如搜索：<心经 或 心经>
- 支持多个关键词搜索，用空格隔开，如：金刚经 般若
- 注意：空格用于分隔关键词，其他标点符号会被视为搜索内容的一部分（项目为考据级别）

{{.translator.Translate "complex_search" .lang}}

本搜索引擎支持使用多个搜索词进行复杂搜索，通过空格分隔不同的搜索词，系统会返回同时包含所有搜索词的结果。
1. 多个搜索词之间的逻辑关系为AND（同时包含）
2. 支持最多3个搜索词组合
3. 每个搜索词都遵循相同的精确匹配规则
4. 适合需要精确定位包含多个关键词的内容

{{.translator.Translate "complex_search_examples" .lang}}：
- 搜索"金刚经 般若 波罗蜜"：返回同时包含"金刚经"、"般若"和"波罗蜜"的内容
- 搜索"道 可道 非常道"：返回同时包含这三个关键词的内容
- 搜索"《论语》 子曰"：返回《论语》中包含"子曰"的内容

{{.translator.Translate "scholarly_search_features" .lang}}

{{.translator.Translate "what_is_scholarly_search" .lang}}

考据级搜索是指本搜索引擎专为学术研究、文献考据等场景设计，提供极高精度的搜索功能。与传统搜索引擎不同，本系统不会对搜索词进行分词处理，而是将整个搜索词（包括标点符号）作为完整的匹配条件，确保搜索结果的准确性和完整性。

搜索粒度

传统搜索引擎通常以一篇文章或一个文件为搜索粒度，在匹配时会返回整个文档作为结果。而本考据级搜索引擎采用更精细的句子级搜索粒度：

  • 传统搜索引擎：以整篇文章为单位返回搜索结果
  • 考据级搜索引擎：以句子为单位返回搜索结果
  • 每个搜索结果都精确指向匹配内容所在的句子
  • 支持查看句子的上下文，便于理解匹配内容的完整含义
  • 特别适合需要精确定位特定语句、引用或证据的学术研究场景
{{.translator.Translate "100_precise_search" .lang}}

1. 只要文件已被创建索引，任何文字组合（包括标点符号）都能被100%精准搜索到
2. 搜索词中的每个字符（包括空格、标点符号）都会被精确匹配，不会被忽略或拆分
3. 支持长句、特殊符号、古籍标点等复杂搜索场景
4. 特别适合需要精确查找特定语句、引用或古籍原文的场景

{{.translator.Translate "no_segmentation_issues" .lang}}

传统搜索引擎通常会对搜索词进行分词处理，可能导致以下问题：
- 长句被拆分为多个短词，失去原有的上下文关系
- 特殊词汇、专业术语或古籍中的生僻词汇可能被错误分词
- 标点符号被忽略，无法精确匹配原文
- 搜索结果可能包含无关内容，需要用户自行筛选

而本搜索引擎采用全文精确匹配技术，完全不会出现上述分词遗漏问题。无论搜索词多么复杂，只要文件中存在完全匹配的内容，就能被准确检索出来。

{{.translator.Translate "search_term_length_limit" .lang}}

为了优化索引性能和搜索效率，本搜索引擎对搜索词的长度进行了限制：
- 单个搜索词的最大长度为5个字符
- 如果搜索词超过5个字符，系统会自动截取前5个字符进行搜索
- 这个限制仅适用于单个搜索词，多个搜索词组合不受影响
- 例如：搜索"阿弥陀佛"（4个字符）会被完整匹配，搜索"阿弥陀佛菩萨"（6个字符）会被截取为"阿弥陀佛"（前5个字符）进行搜索

这个长度限制是在创建索引时设定的，确保了索引文件的合理大小和搜索的高效性，同时足以满足大多数考据和研究场景的需求。

{{.translator.Translate "usage_examples" .lang}}

- 搜索"道可道，非常道"：只会匹配包含完整这句话的文件，不会匹配单独出现"道"或"可道"的内容
- 搜索"《金刚经》云：凡所有相，皆是虚妄"：会精确匹配包含完整引用的文件
- 搜索"1+1=2"：会精确匹配包含该数学表达式的文件，包括等号和数字
- 搜索特殊符号组合：如"【】、「」、『』"等古籍标点，都能被精确匹配

{{.translator.Translate "single_machine_usage" .lang}}

应用默认配置为单机使用模式，通过 http://localhost:9981 访问。 适合个人用户在本地电脑上索引和搜索文件。

{{.translator.Translate "lan_usage" .lang}}

应用默认绑定到所有网络接口，局域网内其他设备可以直接通过服务器的IP地址访问：

  • 1. 确定服务器在局域网内的IP地址（如 192.168.1.100）
  • 2. 局域网内其他设备可以通过 http://[服务器IP]:9981 访问
{{.translator.Translate "internet_usage" .lang}}

可以将应用部署为互联网可访问的网站：

  • 1. 将应用部署到云服务器或VPS
  • 2. 配置服务器防火墙，开放相应端口（默认9981）
  • 3. 可选：配置域名解析到服务器IP，使用反向代理（如Nginx）提供HTTPS支持

{{.translator.Translate "faq" .lang}}

1. 索引页面无法访问？

索引页面只允许本地访问（127.0.0.1），请确保从本地浏览器访问。

2. 索引密码是什么？

默认密码是"123456"，可以在config.yaml文件中修改。

3. 如何修改默认语言？

进入设置页面，选择默认语言并点击保存按钮。

4. 搜索结果不完整？

请确保相关文件已经被索引，索引过程可能需要一些时间。

5. 如何更新索引？

如果文件内容发生变化，只需重新建立索引即可更新索引数据。在索引页面中，选择相同的目录或文件，然后点击"创建索引"按钮重新索引。
